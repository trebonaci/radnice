Společný projekt Ondřeje, Claudea a Codexu. Veřejná prezentace je plánovaná jako stránka na trebonaci.cz; toto repo je pracovní zdroj pravdy pro specifikaci, metodiku, model dat, prompty a kód.

## Jak pracujeme

- Jeden úkol = jedno GitHub issue s jasným kritériem hotovo.
- Změny patří do samostatné větve a pull requestu; Ondřej je kontroluje a rozhoduje o sloučení.
- Sloučení do `main` neznamená automatické zveřejnění na webu.
- Veřejné výstupy musí odkazovat na původní zdroj a Ondřej je schvaluje.
- Do repozitáře nedávat hesla, tokeny ani neveřejné interní podklady.
